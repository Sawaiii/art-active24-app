# UX-спека: тактильность, жесты, анимации

## Системный язык платформы (требование заказчика)

Каждое приложение «вписано» в свою платформу, айдентика Арт-Актив ложится поверх:
- **iOS** — HIG; на iOS 26+ Liquid Glass (системные таб-бар, навбары, шторки — стекло автоматически;
  свои плавающие элементы — `.glassEffect` с фолбэком `.ultraThinMaterial` на iOS 17–25), SF Symbols,
  large titles, свайп назад, `.searchable`, `presentationDetents`, системный DatePicker.
- **Android** — Material 3 (Expressive), predictive back, edge-to-edge, ModalBottomSheet, Material3 DatePicker,
  Material Symbols, системный splash. Dynamic color выключен — бренд важнее.
- **Язык интерфейса — язык системы**: ru (основной) + en; склонения через plural-ресурсы
  (String Catalog / plurals.xml), цены и даты — по локали устройства. Android — per-app language.
- Тёмная тема — системная, палитра выведена из айдентики.

Правило: каждое действие пользователя получает ответ ≤100 мс — визуальный и, где уместно,
тактильный. Никаких «мёртвых» нажатий и голых спиннеров.

## Haptics — словарь (одинаково на iOS и Android)

| Событие | iOS | Android |
|---|---|---|
| Нажатие таба, чипа, сегмента, выбор комплекта | `.selection` | `HapticFeedbackConstants.CLOCK_TICK` / `SEGMENT_TICK` |
| Степпер кол-ва / часов / дней (+/−), каждый шаг прокрутки пикера | `.selection` | `SEGMENT_FREQUENT_TICK` |
| Упёрлись в мин/макс степпера | `.impact(.rigid, 0.5)` | `REJECT` |
| Добавлено в корзину | `.impact(.medium)` + анимация «полёт в таб» | `CONFIRM` |
| В избранное / убрали | `.impact(.light)` + «сердце-пульс» | `CONTEXT_CLICK` |
| Свайп-удаление перешёл порог | `.impact(.medium)` | `GESTURE_THRESHOLD_ACTIVATE` |
| Pull-to-refresh перешёл порог | `.impact(.light)` | `GESTURE_THRESHOLD_ACTIVATE` |
| Заказ оформлен | `.notification(.success)` + конфетти-чек | `CONFIRM` + анимация |
| Ошибка (валидация, сеть) | `.notification(.error)` + shake поля | `REJECT` + shake |
| Код из SMS введён полностью | `.notification(.success)` | `CONFIRM` |
| Long-press на карточке (быстрый просмотр) | `.impact(.soft)` | `LONG_PRESS` |

Реализация — единый сервис `Haptics` с этими событиями; экраны вызывают событие, а не API платформы.
Уважаем системную настройку «вибрация выкл.» и Reduce Motion.

## Жесты и слайды

- **Галерея товара**: горизонтальный пейджинг с индикатором, тап → полноэкранный просмотр,
  pinch/double-tap zoom, свайп вниз — закрыть с затуханием фона (interactive dismiss).
- **Комплекты/варианты**: горизонтальная карусель карточек с snap; выбранный — подсветка + haptic.
- **Листинги**: pull-to-refresh, бесконечная подгрузка, long-press → peek (быстрый просмотр
  с кнопками «В корзину» / «В избранное»).
- **Корзина**: свайп влево — удалить (с Undo-снекбаром 4 с), свайп вправо — в избранное.
- **Bottom sheets** с «ручкой» для фильтров, сортировки, выбора даты/времени, допов;
  закрытие свайпом вниз, промежуточные высоты (medium/large).
- **Back-swipe** от края на iOS везде; predictive back на Android 14+.
- **Шапка категории** сворачивается при скролле (large title → inline), баннер с параллаксом.
- **Sticky-бар «В корзину»** внизу карточки: цена пересчитывается с анимацией цифр
  (numeric content transition) при смене комплекта/кол-ва/времени.

## Переходы и загрузка

- Переход «плитка листинга → карточка»: общий элемент (фото + название) — matched geometry /
  shared element transition.
- Skeleton-плейсхолдеры той же формы, что контент (shimmer), вместо спиннеров.
- Картинки: плавное проявление (crossfade 200 мс), низкокачественное превью → полное.
- Бейдж корзины в таб-баре — «подпрыгивает» при добавлении.
- Пустые состояния — с иллюстрацией и действием («Перейти в каталог»), не просто текст.

## Приятные функции

- Недавно просмотренные (локально), «Вы смотрели» на главной.
- Избранное (локально для гостя, синхронизация после входа).
- Поиск: подсказки по мере ввода, история запросов, популярные запросы.
- Повторить заказ одним нажатием из ЛК.
- Поделиться товаром (ссылка на сайт; deep link открывает карточку в приложении).
- Звонок / WhatsApp / Telegram менеджеру из карточки и из заказа.
- Push о смене статуса заказа; бейдж непрочитанных изменений в ЛК.
- Офлайн: последний загруженный каталог и открытые карточки доступны без сети, баннер «Нет сети».
- Тёмная тема — только если она есть в айдентике сайта; иначе фиксируем светлую (айдентика важнее).
- Доступность: Dynamic Type / fontScale, VoiceOver/TalkBack-подписи, контраст ≥ 4.5:1.
